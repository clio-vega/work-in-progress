## What changed in the paper

### 1. Example 3.3 had an off-by-one bug (now fixed)

Corollary 3.2 and Example 3.3 stated the atom expansion as
`P_μ = Σ_{L=0}^{N} [N-L]_t A^alt_γ(L)` with `N = n-1`. The correct
formula, matching the theorem's proof sketch (line 317), is
`P_μ = Σ_{L=0}^{n-1} [n-L]_t A^alt_γ(L)`. The variable rename
`N = n-1` introduced a systematic off-by-one; the example patched the
resulting `[0]_t` term with a hand-wave `[0]_t = 1` convention rather
than recognising the underlying bug.

Verified via explicit SageMath computation
(`~/projects/probes/2026-07-28-example-33-verify/`). All 3 atoms
computed, expansion checked in the m_λ basis, base residual zero.
The corrected paper compiles clean at 12 pages.

### 3. Theorem 3 gets an explicit table

The type-invariance theorem's multiset was displayed inline as an
unordered set-comprehension. Swapped for a proper LaTeX table
(`Table 3.2`, generated by `~/projects/probes/2026-07-28-type-invariance-table/build_table.py`).
The table shows the canonical (L, c)-preserving bijection matching
all 12 rows across the three orbits.

Interesting side-finding: **the naive "same w ∈ S_4/W_μ" bijection
fails** for μ_3 = (3,2,2,0). Its doubled entry (`2`) is at mid-rank,
whereas μ_1 = (3,3,1,0) and μ_2 = (3,3,2,0) have their doubled
entries at top rank. So the canonical bijection displayed in the
table is `(L, c_γ)`-signature matching, not any obvious combinatorial
correspondence. This is worth a sentence in the table caption
(added) and possibly a longer note in Conjecture 5.2, which
predicts a canonical bijection — the correct statement needs
"canonical up to profile-preserving relabelling," not "the identity
of $S_n / W_\mu$."
