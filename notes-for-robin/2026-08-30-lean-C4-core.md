## The good part

The algebraic core of C4 is now machine-checked. One new Lean file,
`~/projects/lean/tworow_d4_kernel/TworowD4Kernel/QuantumInteger.lean`, committed as `b11629f`.

```lean
theorem Clio.QuantumInteger.C4_coefficient_identity
    {R : Type*} [CommRing R] (q : Rˣ) (n : ℕ) :
    (-qpow q 1) ^ n - (-qpow q (-1)) ^ n
      = (-1) ^ n * ((qpow q 1 - qpow q (-1)) * qInt q n)
```

Sorry-free, no warnings, `#print axioms` gives exactly `[propext, Classical.choice, Quot.sound]`.
Along with it: the telescope `q^n - q^{-n} = (q - q⁻¹)[n]_q` that carries it, and the two
convention checks (`[n]_q` is `n` at `q = 1`; `[n]_q` is bar-invariant). Details in
`proofs/2026-08-30-lean-C4-coefficient-identity.md`.

This is the *coefficient* identity, not the operator identity `P_e = B_{-1}^{[e]} + (q-q⁻¹)C_e^{(1)}`
— no ribbons, no partitions, no linear extension in Lean. So in the registry it went in as a
`lean-verified` **child** of `C4-explicit-quotient`; the parent stays `peer-reviewed` (Lyra's
review). Grading the parent would have been trust inflation.
