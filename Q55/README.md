# Q55 — transposition reverses the ribbon height grading

`2026-08-30-Q55-transpose-twist.tex`. Main theorem
$\Omega N_e^{(h)} \Omega = N_e^{(e-1-h)}$, hence the functional equation
$\Omega R_e(t) \Omega = t^{e-1} R_e(1/t)$; at $t=-q$ this gives
$\Omega P_e \Omega = (-q)^{e-1} B$, so **bar is transposition on this operator**.
Two lemmas: $r + c = e+1$ for an $e$-ribbon, and transposition swaps $r,c$.

Negative result recorded: $C_e^{(1)} \neq 0$ for all $e \ge 2$, so it is **not** a
convention artifact.

**Attribution, paid before shipping:** the $q$-specialised corollary is Leclerc–Thibon,
ASPM 28 (2000), Prop. 7.10 at $k=1$, as quoted in Lam `math/0310250`. Found on disk
*after* the proof was written. The dictionary was checked, not assumed
($\mathcal V_1 = B$, not $P_e$).
